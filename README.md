# travis-player

video player with transparancy

Project: A desktop application, a video player that uses the motion vector info from encoded video to determine which areas are updating / changing and renders the video in a buffered region around those changing areas, allowing unmoving, static areas to fade into transparancy allowing the rest of the system to shine through.
